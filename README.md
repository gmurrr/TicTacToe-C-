# Tic-Tac-Toe (Kółko i Krzyżyk) w C# 

Klasyczna gra w kółko i krzyżyk stworzona jako aplikacja konsolowa. Projekt został napisany w języku C# i opiera się na zasadach programowania obiektowego (OOP), co zapewnia czytelną strukturę i łatwość rozbudowy kodu.

##  Funkcjonalności

* Gra dla dwóch graczy (X oraz O) w trybie lokalnym.
* Przejrzysty i czytelny interfejs renderowany bezpośrednio w oknie konsoli.
* Walidacja wprowadzanych danych (zabezpieczenie przed wyborem zajętego pola lub wpisaniem nieprawidłowych znaków).
* Automatyczne wykrywanie zwycięstwa jednego z graczy lub remisu.

##  Technologie i narzędzia

* **Język:** C#
* **Platforma:** .NET
* **Paradygmat:** Programowanie obiektowe (OOP)
